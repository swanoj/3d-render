# Photos from the nights

Make a folder named after the night's slug (its date) and drop the photos in:

```
app/photos/2026-10-16/01.jpg
app/photos/2026-10-16/02.jpg
```

They show on that night's page as a gallery, and the latest night's photos run through the film strip on the home page, in file-name order. JPEG, PNG, WebP or AVIF; around 2000px on the long side is plenty. Keep faces out of frame.
